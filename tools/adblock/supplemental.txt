# Project-maintained supplement for the bundled ad/tracker filter rules.
#
# WHY THIS FILE EXISTS
#   The upstream snapshot (tools/adblock/upstream-hosts.txt, Peter Lowe's list) is strong on
#   western ad networks but thin on Chinese ones, and it contains no path rules at all. This
#   file is the project's own addition: Chinese ad networks, Chinese analytics/tracking
#   endpoints, and the path fragments that catch ad URLs served from domains that are not
#   themselves ad domains.
#
# HOW TO READ IT
#   Everything here is hand-maintained, and that is stated plainly in docs/AD_BLOCKING.md —
#   this file is NOT presented as a complete filter list. Each line is one endpoint whose
#   only job is advertising, tracking or attribution.
#
# RULES FOR ADDING AN ENTRY (do not skip this)
#   * Add the narrowest host that is actually the ad endpoint. Never add a CDN root that
#     also serves page content (e.g. `alicdn.com`, `bdstatic.com`, `qpic.cn`, `byteimg.com`).
#   * Prefer a subdomain (`pos.baidu.com`) over a registrable domain when only the
#     subdomain is advertising.
#   * A wrong entry is harmless (it never matches); a too-broad entry is destructive
#     (it breaks pages). When in doubt, leave it out.
#   * Path fragments must be at least 4 characters long — the parser drops shorter ones,
#     because `/a` is a substring of nearly every third-party URL.
#
# FORMAT (identical to the bundled rules file)
#   host              block this host and every subdomain of it
#   @@host            exception: never block this host, whatever else says otherwise
#   /path             block third-party requests whose path+query contains this fragment
#
